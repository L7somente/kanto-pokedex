# Pokédex de Kanto

Pokédex interativa com os 151 Pokémon originais, imagens oficiais, busca, filtros por tipo, favoritos, atributos e linhas evolutivas.

## Recursos

- 151 Pokémon da primeira geração
- Busca por nome ou número
- Filtro por tipo e ordenação
- Favoritos salvos no navegador
- Altura, peso, habilidades e atributos base
- Linhas evolutivas navegáveis
- Layout responsivo para celular e computador

## Executar localmente

Abra `dist/index.html` no navegador ou sirva a pasta `dist` com um servidor estático.

## Fontes

As imagens são carregadas do domínio oficial `assets.pokemon.com`. Informações detalhadas são consultadas pela PokéAPI.
